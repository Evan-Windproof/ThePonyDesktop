# TPD 使用的 HoofTTY 图形 ABI（实验性）

追加到现有 `int 0x82`。RAX=调用号，RDI/RSi=两个整数参数；RAX 返回结果。
现有 0 write / 1 uptime / 2 yield / 3 exit 保持不变。
沿用入口的 CPL3、当前活跃用户任务、代码 RIP 和栈 RSP 检查。
系统只允许一个用户任务，显示会话归该任务；非会话绘图/输入返回 -1。

| 号 | 用途 | 参数及结果 |
|---|---|---|
| 4 | 申请图形显示/鼠标会话 | 无参数；成功返回 width \| height<<16；-16 已占用，-19 显示/鼠标不可用 |
| 5 | 绘制实色矩形 | RDI=x \| y<<16 \| w<<32 \| h<<48，各 unsigned16；RSI=0xRRGGBB；成功0 |
| 6 | 输入状态快照并让出一 tick | 无参数；返回 x[15:0]、y[31:16]、鼠标按钮[34:32]、ASCII键[47:40]，无键为0 |
| 7 | 释放显示会话 | 幂等；禁用 AUX、排空输入、恢复终端绘制并清屏；成功0 |
| 8 | 透明背景 ASCII 字形 | RDI=x \| y<<16；RSI=字符[7:0] \| RGB24<<8；按已有 5×7 字形二倍绘制；成功0 |

矩形超屏部分裁剪；空矩形不写内存；无效字形忽略。返回0仅表示服务接受，不代表有可见像素。
不接受用户地址，不直接映射 framebuffer，因此新接口不需要新增用户缓冲复制逻辑。
坐标可由无符号位域完整表达；客户端在打包之前限制窗口坐标。
应用通过调用7后调用3正常退出；即使未调用7，任务回收也会关闭会话。

无事件队列：该接口不承诺保留两个采样之间的按钮边沿；UI 识别相邻快照的左键上升/下降沿。
会话前后的待输入被清理，避免桌面按键流入 Shell 命令行；不保存进入前尚未完成的输入。
当前服务编号没有跨版本协商，未来应增加 ABI 版本查询，不适宜视为稳定公共接口。

## v0.1.1 可选扩展

9 begin：仅显示会话所有者可调用。建立后备缓冲模式，重复返回 -16，超过1024×768 返回 -19。
10 present：仅显示会话所有者可调用；未开启缓冲返回 -1，否则提交修改，返回0。
原4–8号服务保持兼容。开启缓冲后5/8只画入后备缓冲；7及任务回收均关闭缓冲再恢复终端。
缓冲为内核固定上限1024×768×4（3 MiB）的静态保留区，始终映射在内核权限页内，不向用户导出指针，
无用户可控分配长度，无每次进入的内存分配。begin复制当前显示，重置脏范围；退出取消缓冲状态，下次重新初始化。
present按脏包围盒比较最终像素，只把不同颜色写入真实 framebuffer；并非显示硬件页翻转，不承诺无撕裂。
6号输入返回格式不变：按钮变化入64槽环形队列（最多63个记录），同按钮移动合并；满时丢弃最旧记录。
无待处理事件时先睡眠再采样，减少旧版固定额外一tick的坐标延迟。
